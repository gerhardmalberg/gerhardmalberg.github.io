# gerhardmalberg.github.io
Minimal personal landing page. Plain HTML and inline CSS, with no build step,
JavaScript, external fonts or dependencies.

Preview locally from this directory:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. Press Ctrl+C to stop the server.
GitHub Pages publication is configured separately; these files do not enable it.
